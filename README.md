# ☕ Bootcamp Itaú Java com Inteligência Artificial

Repositório dedicado a documentar minha jornada e armazenar os códigos, desafios e projetos práticos desenvolvidos durante o **Bootcamp Itaú Java com Inteligência Artificial** na plataforma [DIO (Digital Innovation One)](https://web.dio.me/track/itau-java-com-inteligencia-artificial).

## 🎯 Objetivo
O principal objetivo deste repositório é servir como um portfólio de estudos, organizando o aprendizado de conceitos fundamentais e avançados do desenvolvimento back-end com Java e a integração com ferramentas de Inteligência Artificial.

## 🛠️ Tecnologias e Ferramentas Exploradas
*   **Linguagem principal:** Java
*   **Frameworks:** Spring Boot, Spring.
*   **Outros:** Integração com APIs.
*   **Controle de Versão:** Git e GitHub

## 📂 Estrutura do Repositório

Para facilitar a navegação e o acompanhamento do progresso, os diretórios estão organizados da seguinte forma:

*   📁 `aulas/`: Anotações teóricas e códigos de fixação desenvolvidos durante as aulas em vídeo.
*   📁 `desafios/`: Resoluções dos desafios de código propostos na plataforma, focados em lógica de programação e algoritmos.
*   📁 `projetos/`: Projetos práticos e completos construídos ao longo do bootcamp.
